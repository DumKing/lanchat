# DesktopPet Runtime 与 Windows Desktop Pet Generator Skill 对接规范（V2）

## 1. 设计目标

本文档规定 **DesktopPet Runtime** 如何适配 **Windows Desktop Pet
Generator Skill**。

原则：

-   Skill 负责生成资源
-   Runtime 负责读取资源
-   Runtime 不关心角色类型（熊猫、青蛙、猫咪、兽耳娘等）
-   Runtime 仅依赖统一资源协议

------------------------------------------------------------------------

# 2. Skill 与 Runtime 架构

``` text
用户
 │
 ▼
Windows Desktop Pet Generator Skill
 │
 ├── Character
 ├── Idle
 ├── Alert
 ├── Move
 ├── Interact
 ├── Life
 ├── manifest.json
 │
 ▼
DesktopPet Runtime
 │
 ▼
状态机
 │
 ▼
桌宠展示
```

------------------------------------------------------------------------

# 3. Resource Protocol（资源协议）

每个角色必须包含：

``` text
Character/
│
├── manifest.json
├── preview.png
├── icon.png
│
├── Idle/
├── Alert/
├── Move/
├── Interact/
└── Life/
```

Runtime 不识别角色名称，只识别上述目录。

------------------------------------------------------------------------

# 4. manifest.json

``` json
{
  "id":"frog",
  "name":"青蛙",
  "version":"1.0",
  "resolution":512,
  "fps":12,
  "transparent":true,
  "states":[
    "Idle",
    "Alert",
    "Move",
    "Interact",
    "Life"
  ],
  "defaultState":"Idle"
}
```

------------------------------------------------------------------------

# 5. 状态与 Skill 对应

  Runtime状态   Skill目录   默认行为
  ------------- ----------- --------------
  Idle          Idle/       随机循环
  Alert         Alert/      打断其它状态
  Move          Move/       桌面移动
  Interact      Interact/   鼠标事件
  Life          Life/       随机生活动作

------------------------------------------------------------------------

# 6. Runtime 状态机

``` text
                 启动
                  │
                  ▼
               Idle
      ┌────────┼────────┐
      ▼        ▼        ▼
    Life      Move    Alert
      │         │        │
      └────┐    │    ┌───┘
           ▼    ▼    ▼
        Interact
           │
           ▼
     恢复上一状态
```

优先级：

Alert \> Interact \> Move \> Life \> Idle

------------------------------------------------------------------------

# 7. 状态触发

## Idle

进入：

-   软件启动
-   所有状态结束

退出：

-   定时进入 Life
-   定时进入 Move
-   收到 Alert
-   鼠标事件

------------------------------------------------------------------------

## Life

触发：

20\~90 秒随机

退出：

动作结束返回 Idle

------------------------------------------------------------------------

## Move

触发：

60\~180 秒随机

或巡逻模式

退出：

移动结束返回 Idle

------------------------------------------------------------------------

## Alert

触发：

-   新消息
-   下载完成
-   系统通知
-   用户事件

立即打断当前状态。

结束恢复上一状态。

------------------------------------------------------------------------

## Interact

触发：

-   点击
-   双击
-   拖拽
-   长按
-   鼠标悬停（可选）

结束恢复上一状态。

------------------------------------------------------------------------

# 8. Runtime 播放策略

Idle：

-   每 15\~40 秒随机切换一个动作
-   随机播放 Idle 目录资源

Life：

-   每 30\~120 秒随机执行一次
-   动作结束返回 Idle

Move：

-   每 60\~180 秒随机巡逻
-   随机选择 Move 动画

Alert：

-   收到事件立即播放
-   结束恢复

Interact：

-   即时响应
-   完成恢复

------------------------------------------------------------------------

# 9. Runtime 导入校验

必须校验：

-   PNG
-   透明背景
-   512×512
-   每张仅一个角色
-   身体完整
-   五个状态目录存在
-   manifest.json 存在

校验失败拒绝导入。

------------------------------------------------------------------------

# 10. Runtime 与 Skill 解耦原则

Runtime 永远不判断：

-   熊猫
-   青蛙
-   猫咪
-   狐耳娘

Runtime 仅判断：

-   Idle
-   Alert
-   Move
-   Interact
-   Life

新增任何角色，只要符合 Skill 输出协议，无需修改 Runtime。

------------------------------------------------------------------------

# 11. 扩展建议

未来可扩展：

-   Emotion（情绪）
-   Sit（坐下）
-   Sleep（睡眠）
-   Fly（飞行）
-   Swim（游泳）

Skill 增加资源目录，Runtime 读取 manifest
中的状态即可自动支持，无需修改核心逻辑。
