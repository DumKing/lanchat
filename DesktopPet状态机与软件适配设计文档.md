# DesktopPet 状态机与软件适配设计文档

## 1. 目标

本文档定义 Windows DesktopPet
的统一状态机，适用于熊猫、青蛙、猫咪、兽耳娘、水豚、柴犬、小机器人等所有角色。

所有角色共享同一套行为逻辑，仅替换角色资源即可。

------------------------------------------------------------------------

# 2. 状态

  状态                说明           是否循环
------------------- -------------- ----------
  Idle（待机）        默认状态       是
  Life（生活）        自主生活动作   是
  Interact（互动）    用户交互       否
  Alert（告警）       消息提醒       否
  Move（移动/蹦迪）   桌面移动       是

------------------------------------------------------------------------

# 3. 状态优先级

Alert \> Interact \> Move \> Life \> Idle

高优先级状态可打断低优先级状态，结束后恢复。

------------------------------------------------------------------------

# 4. 状态流转

``` text
                启动
                  │
                  ▼
            Idle（待机）
           ╱    │     ╲
          ╱     │      ╲
     Life   Move   Alert
       │       │       │
       └────┐  │  ┌────┘
            ▼  ▼  ▼
       Interact（互动）
            │
            ▼
      返回 Idle 或 Life
```

------------------------------------------------------------------------

# 5. 各状态触发规则

## Idle（待机）

默认进入。

### 进入条件

-   软件启动
-   所有状态结束
-   无事件发生

### 自动切换

-   超过 20\~60 秒 → Life
-   收到蹦迪告警 → Move
-   收到普通告警 → Alert
-   鼠标点击 → Interact

------------------------------------------------------------------------

## Life（生活）

例如：

-   喝奶茶
-   睡觉
-   看书
-   玩手机
-   钓鱼
-   听音乐

### 触发

随机时间：

20\~90 秒

随机动作：

10\~30 秒

### 结束

结束后：

返回 Idle。

------------------------------------------------------------------------

## Move（移动）

例如：

-   慢走
-   跑步
-   跳跃
-   蹦迪
-   转圈

### 触发

随机：

60\~180 秒

或者：

用户开启自动巡逻。

### 结束

完成路线：

返回 Idle。

------------------------------------------------------------------------

## Alert（告警）

例如：

-   新消息
-   CPU过高
-   软件通知
-   下载完成
-   邮件提醒

### 触发

收到通知事件。

### 动作

-   挥手
-   举牌
-   喇叭
-   感叹号
-   跳跃提醒

### 超时

5\~15 秒自动结束。

返回 Idle。

------------------------------------------------------------------------

## Interact（互动）

鼠标：

-   点击
-   双击
-   长按
-   拖拽
-   松开

动作：

-   摸头
-   害羞
-   生气
-   开心
-   比心
-   飞吻

结束：

返回之前状态。

------------------------------------------------------------------------

# 6. 事件

  事件       状态
---------- ----------
  软件启动   Idle
  定时器     Life
  巡逻       Move
  消息通知   Alert
  鼠标点击   Interact
  鼠标拖拽   Interact
  动画结束   Idle

# 8. manifest.json 示例

``` json
{
  "character":"Frog",
  "states":["Idle","Life","Move","Alert","Interact"],
  "default":"Idle",
  "fps":24,
  "transparent":true,
  "loop":true
}
```

# 9. 建议

-   Idle 占 60%
-   Life 占 20%
-   Move 占 15%
-   Alert 占 3%
-   Interact 占 2%

所有角色共享状态机，仅替换动画资源即可。
