# LanChat v0.6.1

本版本完善视觉模型中心，提供可校验、可下载、可卸载的真实模型组合，并改善本机识别人员的参考照片管理。

## 视觉模型

- 模型中心现在明确展示当前已启用的模型，可卸载未启用的已下载模型。
- 新增 `ArcFace Buffalo-SC` ONNX Runtime Profile，使用 ArcFace 512 维人脸特征和现有 YoutuReID 人体特征。
- 新增两套独立的官方 Open Model Zoo 模型包：`OMZ Retail-0288`、`OMZ Retail-0286`。
- 模型发布流水线会从官方 Open Model Zoo 下载原始 IR，再生成并校验 XML/BIN 成对资源；不会再把基线模型改名发布。
- 当前客户端可下载和完整性校验 OpenVINO 包；完整 OpenVINO 推理执行器尚未随客户端发布时，模型中心会阻止激活并给出明确提示。

## 许可证说明

- `ArcFace Buffalo-SC` 使用 InsightFace 公开预训练权重，仅面向非商用学习与研究场景。
- 商业使用、二次分发或其他超出上述范围的用途，必须由使用者取得相应授权。

## 本机识别人员

- 识别人员详情现在可删除单张参考照片；为保持识别质量，每个人至少保留三张参考照片。
- 删除照片时会同步清理该人员旧的本机特征，避免已删除照片继续影响识别结果。

## 下载与更新

- Windows 提供安装包和绿色免安装包。
- macOS 提供 DMG 安装包。
- 本版本为强制更新；最低支持版本为 `0.0.0`。
