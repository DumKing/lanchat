# LanChat v0.4.2

本版本聚焦桌宠告警、私聊通话与自动更新体验的稳定性修复。

## 本版重点

- 桌宠告警反馈后会立即清除未处理角标和详情弹窗；增加状态版本保护，避免旧的异步状态把已处理告警重新显示出来。
- 语音和视频通话调整为独立通话窗口，可跨屏移动；窗口与备用通话条均使用不透明背景。
- 默认折叠的通话窗在展开后会正确补挂本地摄像头和远端视频流。
- 桌宠接听或拒绝通话时优先处理通话信令，主窗口定位聊天不再拖慢接听响应。
- 更新检查与下载会在每次请求前重新读取系统代理配置，适应软件运行期间的代理切换。
- 修复桌宠告警详情偶发丢失昵称、IP 并回退为未知设备的问题。

## 下载与更新

- Windows 可下载安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- 绿色版解压后运行 `lanchat.exe`；系统缺少 WebView2 Runtime 时需先安装 Microsoft Edge WebView2 Runtime。
- macOS 可下载 DMG 安装包；未签名版本首次打开时可能需要在系统安全设置中确认。
