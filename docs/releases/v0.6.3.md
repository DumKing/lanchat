# LanChat v0.6.3

本版本完善视觉模型运行时的切换和本机人员库可用性，提供完整的 Windows OpenVINO 模型运行环境。

## 视觉模型与本机识别人员

- Windows 安装包和绿色版会随程序携带 OpenVINO Runtime；支持 OpenVINO 的视觉模型 Profile 可在重启后直接运行，不再仅能下载。
- 修复从下载模型切回“内置基础模型”时错误提示 `VISION_MODEL_PROFILE_NOT_INSTALLED` 的问题。
- 模型中心会正确显示下次启动采用的内置模型；当前会话保持运行，重启后完成模型切换。
- 修复模型不可用、正在切换或缺少运行时时，本机识别人员列表被错误清空的问题；已保存人员及参考照片仍可查看和刷新。

## 操作反馈

- 模型目录刷新、安装、启用、卸载，以及更新相关的操作失败，统一使用应用内小型错误弹窗提示。

## 更新

- Windows 提供安装包与绿色免安装包；macOS 提供 DMG 安装包。
- 本版本为强制更新，最低支持版本为 `0.0.0`。
