# LanChat v0.3.0

LanChat v0.3.0 继续同时发布完整版和轻量版：

- `lanchat`：完整版，包含局域网聊天、设备发现、频道、游戏、桌宠告警器。
- `lanchat-lite`：轻量版，只保留桌宠告警器、狼来了排行榜、桌宠设置和外部推送配置。

## 本版重点

- Full 和 Lite 互斥启动：同一台电脑只能运行一个版本，再打开另一个版本会弹出提示。
- Lite 告警器和 Full 告警器互通，同时 Lite 会作为告警设备出现在完整版设备列表中。
- Lite 不支持聊天、频道、游戏、文件等完整版能力；历史私聊记录仍可浏览，但当前设备为 Lite 时禁止继续发送消息。
- Lite 桌宠触发行为对齐 Full：双击发送快速告警，Ctrl 双击发送蹦迪告警，告警或蹦迪状态下单击停止。
- Lite 对自己发出的告警处理对齐 Full：单击停止后角标、温度、详情消失，桌宠恢复普通状态。
- Lite 桌宠事件监听增强，避免初始化异常影响桌宠告警 action 注册。
- 桌宠原生点击识别增强，降低透明无边框窗口下单击、双击被拖动行为吞掉的概率。

## 下载建议

- 只需要桌宠报警器：下载 `lanchat-lite` 安装包，或下载 `lanchat-lite-windows-portable.zip` 绿色免安装版。
- 需要聊天、频道、游戏和告警器：下载 `lanchat` 安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- 绿色版解压后直接运行对应 exe；如果系统缺少 WebView2 Runtime，请先安装 Microsoft Edge WebView2 Runtime。

## 桌宠导入规则

下载桌宠资源 ZIP 后请先解压，导入时选择解压后的桌宠根目录，不要选择 ZIP 文件。

桌宠根目录必须包含：

- `manifest.json`
- `icon.png`
- 可选 `preview.png`
- `Idle`、`Alert`、`Move`、`Interact`、`Life` 等动作目录

示例结构：

```text
frog-buddy/
  manifest.json
  icon.png
  preview.png
  Idle/
    breathe/
      idle_breathe_001.png
  Alert/
    surprised/
      alert_surprised_001.png
```

导入后可以在桌宠列表中右键对应桌宠，编辑每个状态的动作持续时间、随机动作数量和动作间隔。用户导入的桌宠也可以在右键设置中删除；内置桌宠不能删除。

## 注意事项

- Lite 只支持桌宠告警能力，不支持聊天、频道、游戏和文件能力。
- Lite 和 Full 共享桌宠资源与桌宠配置，但不共享聊天数据库。
- Windows 下如遇安全软件拦截局域网发现，请在完整版设置里使用网络修复。
