# LanChat v0.3.0

LanChat v0.3.0 恢复为单一正式版发布：

- `lanchat`：包含局域网聊天、设备发现、频道、游戏、桌宠告警器、狼来了排行榜、桌宠设置和外部推送配置。

## 本版重点

- 移除独立轻量版构建，后续安装包、绿色包和 macOS 包只发布 `lanchat`。
- 桌宠原生点击识别增强，降低透明无边框窗口下单击、双击被拖动行为吞掉的概率。
- 桌宠 Ctrl 双击检测增强，避免桌宠窗口焦点不稳定时无法触发蹦迪告警。

## 下载建议

- Windows 用户下载 `lanchat` 安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- macOS 用户下载 `lanchat` DMG。
- 绿色版解压后直接运行 `lanchat.exe`；如果系统缺少 WebView2 Runtime，请先安装 Microsoft Edge WebView2 Runtime。

## 桌宠导入规则

下载桌宠资源 ZIP 后请先解压，导入时选择解压后的桌宠根目录，不要选择 ZIP 文件。

桌宠根目录必须包含：

- `manifest.json`
- `icon.png`
- 可选 `preview.png`
- `Idle`、`Alert`、`Move`、`Interact`、`Life` 等动作目录

示例结构：

```text
frog-buddy/
  manifest.json
  icon.png
  preview.png
  Idle/
    breathe/
      idle_breathe_001.png
  Alert/
    surprised/
      alert_surprised_001.png
```

导入后可以在桌宠列表中右键对应桌宠，编辑每个状态的动作持续时间、随机动作数量和动作间隔。用户导入的桌宠也可以在右键设置中删除；内置桌宠不能删除。

## 注意事项

- Windows 下如遇安全软件拦截局域网发现，请在完整版设置里使用网络修复。
