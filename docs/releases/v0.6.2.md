# LanChat v0.6.2

本版本修复视觉模型组合切换后新增本机识别人员可能失败的问题，并改进参考照片录入体验。

## 视觉识别修复

- 修复多个模型 Profile 复用同一人脸或人体特征组件时，保存人员错误提示 `VISION_EMBEDDING_SPACE_COLLISION` 的问题。
- 特征空间现在以模型组件语义和模态为兼容边界；复用同一组件的不同 Profile 可安全共享已有特征数据。
- 保留真正不兼容的模态或语义冲突校验，避免混用不同模型特征。

## 本机识别人员

- 新增人员时，已选择的每张参考照片都可单独移除，无需放弃整个人员配置后重新录入。

## 更新

- 本版本为强制更新，检测到后需完成升级才能继续使用。
