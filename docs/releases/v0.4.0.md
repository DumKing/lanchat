# LanChat v0.4.0

本版本聚焦桌宠体验、频道操作稳定性与图片查看体验。

## 本版重点

- 新增内置桌宠 `frog-hood-girl`，作为新安装客户端的默认桌宠；原有 `frog-buddy` 保留可选。
- 修复频道解散及布局调整时可能触发全页错误提示的问题；频道解散会在当前界面给出成功或失败结果。
- 图片预览支持滚轮缩放、放大、缩小和一键还原。
- 超管下发公告或通知时可以选择强制打开目标主窗口；无需确认的公告在审核列表仅保留详情查看。
- 完善私聊抖一抖、通话信令与桌宠告警相关稳定性处理。

## 下载与更新

- Windows 可下载安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- 绿色版解压后运行 `lanchat.exe`；系统缺少 WebView2 Runtime 时需先安装 Microsoft Edge WebView2 Runtime。
- macOS 可下载 DMG 安装包；未签名版本首次打开时可能需要在系统安全设置中确认。

## 强制更新

本 Release 标记为强制更新。旧版本检测到 `v0.4.0` 后需要完成更新才能继续使用：

```json
{
  "version": "0.4.0",
  "force": true,
  "min_supported_version": "0.4.0"
}
```
