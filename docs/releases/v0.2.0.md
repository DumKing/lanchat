# LanChat v0.2.0

LanChat v0.2.0 同时发布完整版和轻量版：

- `lanchat`：完整版，包含局域网聊天、设备发现、频道、游戏、桌宠告警器。
- `lanchat-lite`：轻量版，只保留桌宠告警器、狼来了排行榜、桌宠设置和外部推送配置。

## 本版重点

- 新增 Lite 独立构建，运行程序名为 `lanchat-lite.exe`。
- Lite 默认内置 `frog-buddy` 桌宠资源。
- Lite 和 Full 共享用户导入的桌宠资源与桌宠配置。
- Lite 保留昵称设置，告警消息会使用本机昵称。
- Lite 左侧边栏支持收起和展开。
- Lite 桌宠资源支持预览、右键动作配置、用户导入桌宠删除。
- Lite 保留外部推送配置，支持企业微信群机器人和钉钉群机器人。
- Lite 保留狼来了排行榜，按告警反馈真实度统计。

## 下载建议

- 只需要桌宠报警器：下载 `lanchat-lite` 安装包，或下载 `lanchat-lite-windows-portable.zip` 绿色免安装版。
- 需要聊天、频道、游戏和告警器：下载 `lanchat` 安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- 绿色版解压后直接运行对应 exe；如果系统缺少 WebView2 Runtime，请先安装 Microsoft Edge WebView2 Runtime。

## 桌宠导入规则

下载桌宠资源 ZIP 后请先解压，导入时选择解压后的桌宠根目录，不要选择 ZIP 文件。

桌宠根目录必须包含：

- `manifest.json`
- `icon.png`
- 可选 `preview.png`
- `Idle`、`Alert`、`Move`、`Interact`、`Life` 等动作目录

示例结构：

```text
frog-buddy/
  manifest.json
  icon.png
  preview.png
  Idle/
    breathe/
      idle_breathe_001.png
  Alert/
    surprised/
      alert_surprised_001.png
```

导入后可以在桌宠列表中右键对应桌宠，编辑每个状态的动作持续时间、随机动作数量和动作间隔。用户导入的桌宠也可以在右键设置中删除；内置桌宠不能删除。

## 注意事项

- Lite 不注册到聊天列表，也不支持聊天。
- Lite 和 Full 不共享聊天数据库，只共享桌宠资源与桌宠配置。
- Windows 下如遇安全软件拦截局域网发现，请在完整版设置里使用网络修复。
