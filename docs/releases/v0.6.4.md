# LanChat v0.6.4

本版本修复 Windows 视觉模型切换与 OpenVINO Runtime 的发布包加载问题。

## 视觉模型

- 修复 Windows 安装包与绿色版启用 OpenVINO 模型时，错误回退到系统 DLL 搜索并提示找不到 `openvino_c` 的问题。
- 运行时会同时识别应用资源目录与绿色包可执行文件相邻的资源目录；启用模型前会再次确认并加载打包 Runtime。
- 模型中心现在只显示一个已启用模型。切换后，旧模型恢复为“已安装”，新模型显示为“已启用”。

## 发布包校验

- 发布流水线会校验 Windows 绿色包包含 OpenVINO CPU Runtime 所需 DLL，防止资源遗漏后才在用户侧暴露问题。

## 更新

- Windows 提供安装包与绿色免安装包；macOS 提供 DMG 安装包。
