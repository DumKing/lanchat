# 下一版本：本地视觉运行时重构

## 主要变化

- 摄像头采样改为 Raw RGBA 本机 IPC；WebView 不再逐帧编码 JPEG/Base64。
- 新增单独的 Rust 最新帧 Worker：旧帧会被替换，不会在 UI 或 Tauri command 中堆积推理任务。
- 新增视觉运行时状态：用户暂停、活动模型、采样状态与性能状态会写入 V5 视觉表；临时的资源冲突和恢复状态不会跨重启遗留。
- 新增视觉识别工作区，提供模型状态、人员库、队列、P50/P95 延迟、帧接收/丢弃等诊断。
- 新增人员录入保护：新录入人员需要 3 至 30 张参考图；检测到多人合照会拒绝保存；删除本机人员会清理其私有参考图与特征，但不会改写历史告警的姓名快照。

## 兼容与隐私

- 旧 `face_people`、`face_person_samples` 与摄像头告警记录保持兼容读取。
- 参考图片仍只保存在应用私有目录；Raw 帧仅在本机前端到 Rust 的 IPC 中存在，不落盘、不经局域网发送。
- 旧 JPEG 识别命令仅保留一个兼容周期，新的前端采样路径不再主动使用它。

## 发布前人工验收

- 普通工作笔记本以 720p、3 FPS 验证 P95 处理耗时与视觉附加内存。
- 验证摄像头切换、视频通话共享摄像头、最小化到托盘、暂停/恢复、人员删除和局域网策略重投。
