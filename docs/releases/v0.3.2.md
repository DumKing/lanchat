# LanChat v0.3.2

LanChat v0.3.2 重点修复频道公告编辑异常，并完善频道聊天、图片发送、头像同步和桌宠交互体验。

## 本版重点

- 修复编辑频道公告时触发 `ResizeObserver` 异常并进入整页错误保护的问题。
- 修复频道公告保存失败时编辑状态丢失的问题，失败后可继续修改和重试。
- 频道聊天增加 `@成员` 和 `@所有人`，被提及内容在消息中突出显示。
- 支持直接将剪贴板图片粘贴到聊天输入区并发送。
- 优化头像同步：普通在线心跳不再重复传输或刷新头像，仅在启动连接和资料修改时同步。
- 头像更新协议支持区分“未携带头像”和“主动清除头像”，避免覆盖本地缓存。
- 恢复桌宠正常状态下的单击互动，每次单击都会随机播放一轮互动动作并打开主窗口。

## 下载建议

- Windows 用户可下载安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- 绿色版解压后直接运行 `lanchat.exe`；如果系统缺少 WebView2 Runtime，请先安装 Microsoft Edge WebView2 Runtime。
- macOS 用户可下载 DMG 安装包；未签名版本首次运行时可能需要在系统安全设置中确认打开。

## 更新提醒说明

本 Release 会附带 `lanchat-update.json`，更新策略为非强制更新：

```json
{
  "version": "0.3.2",
  "force": false,
  "min_supported_version": "0.0.0"
}
```

客户端检测到新版本后会显示更新弹窗和设置入口升级角标，用户可以关闭提醒后继续使用。
