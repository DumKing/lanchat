# LanChat v0.5.1

本版本重点完善摄像头人物识别、桌宠自动告警和超级管理员配置能力，并补齐启动、频道成员与操作反馈体验。

## 本版重点

- 人物识别升级为人脸与人体外观联合判断，支持人脸确认、人体疑似和多样本加权匹配。
- 单个人员可配置多张参考照片，本机和超管下发均可查看、选择和维护全部样本。
- 人脸阈值、人体阈值、采样频率与连续命中次数均可配置；超管可下发并锁定识别策略。
- 自动识别告警接入桌宠蹦迪、反馈、角标、排行榜及企业微信/钉钉外部推送。
- 手动告警与自动告警分开统计，自动排行榜新增平均识别置信度。
- 桌宠蹦迪增加统一持续时长，快捷键停止动作不会误清理未处理告警。
- 新增开机自启设置，首次安装默认开启，关闭后保留用户选择。
- 超管设置改为全宽单列布局，人员照片支持多选、预览和逐张移除。
- 操作失败统一使用小型弹窗提示，超管密码验证窗口同步缩窄。
- 局域网公共频道成员列表补充本机，并保持本机在线状态与优先展示。
- 人员参考照片取消单张 5MB 限制，仍保留图片解码与完整性校验。

## 下载与更新

- Windows 提供安装包和 `lanchat-windows-portable.zip` 绿色免安装版。
- macOS 提供 DMG 安装包。
- 摄像头识别模型随应用资源一并发布，首次启用时仍需授予摄像头权限。

## 更新策略

本 Release 为强制更新。旧版本检测到 `v0.5.1` 后必须完成安装，最低支持版本为 `0.5.1`。
