# LanChat v0.3.4

LanChat v0.3.4 重点修复了私有频道身份识别，并补齐设备通讯录和图片查看体验。

## 本版重点

- 修复历史 MAC 地址分隔符不一致导致的私有频道问题：`aa-bb-...` 与 `aa:bb:...` 会被识别为同一设备。
- 私有频道中的本机成员会正确显示在线，群主可正常发送消息。
- 历史身份迁移仍优先匹配 MAC；没有 MAC 匹配时，使用本机 WLAN IP 作为兜底修复旧频道成员记录。
- 设备通讯录顶部新增本机设备项，便于查看当前昵称与 MAC 地址；本机不写入远端发现缓存，避免重复发现。
- 图片消息支持点击放大预览，优先使用已下载的本地预览缓存。
- 设备、聊天联系人与频道成员保持稳定排序：本机优先，在线设备优先。
- 桌宠关闭后重新开启时，会重新同步资源并拉起桌宠进程。

## 下载建议

- Windows 用户可下载安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- 绿色版解压后直接运行 `lanchat.exe`；如果系统缺少 WebView2 Runtime，请先安装 Microsoft Edge WebView2 Runtime。
- macOS 用户可下载 DMG 安装包；未签名版本首次运行时可能需要在系统安全设置中确认打开。

## 更新提醒说明

本 Release 会附带 `lanchat-update.json`，更新策略为非强制更新：

```json
{
  "version": "0.3.4",
  "force": false,
  "min_supported_version": "0.0.0"
}
```

客户端检测到新版本后会显示更新弹窗和设置入口升级角标，用户可以关闭提醒后继续使用。
