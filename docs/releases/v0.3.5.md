# LanChat v0.3.5

LanChat v0.3.5 集中修复频道、图片预览与更新体验，并恢复可配置的强制更新能力。

## 本版重点

- 修复局域网公开频道被错误要求私有频道成员资格，导致无法发送消息的问题。
- 修复解散频道时确认框缺少 Tauri ACL 权限而跳转错误页的问题。
- 修复图片消息自动缓存后，本地缓存目录未被资源协议允许访问导致图片立即裂图的问题。
- 软件每次启动都会检查更新；运行期间每 12 小时自动复检。
- 当 Release 被标记为强制更新且发现更高版本时，更新窗口不可关闭，只能下载更新或退出软件。
- 发布工作流支持为某次手动发布指定 `force_update`，用于生成强制更新元数据。

## 下载建议

- Windows 用户可下载安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- 绿色版解压后直接运行 `lanchat.exe`；如果系统缺少 WebView2 Runtime，请先安装 Microsoft Edge WebView2 Runtime。
- macOS 用户可下载 DMG 安装包；未签名版本首次运行时可能需要在系统安全设置中确认打开。

## 更新策略

本 Release 标记为强制更新：

```json
{
  "version": "0.3.5",
  "force": true,
  "min_supported_version": "0.3.5"
}
```

旧版本检测到 `v0.3.5` 后会要求安装新版本才能继续使用。
