# LanChat v0.4.4

本版本修复聊天实时刷新问题，并增加 GitHub 更新检查认证配置。

## 本版重点

- 修复发送消息后当前聊天窗口不立即显示的问题。
- 修复收到新消息后消息列表不自动更新的问题。
- 修复聊天记录没有自动滚动到最新消息的问题。
- 用户查看历史消息时不会被新消息打断，回到底部后会继续跟随最新消息。
- 设置中新增 GitHub API Token 配置，可使用系统凭据库保存 Token，降低 GitHub API 匿名限流影响。

## 下载与更新

- Windows 提供安装包和 `lanchat-windows-portable.zip` 绿色免安装版。
- macOS 提供 DMG 安装包。
- 本 Release 为普通更新，检测到新版本后可选择稍后安装。
