# LanChat v0.8.0 预览版

本版本建立 LanChat 插件平台基础能力，将游戏与视觉识别等扩展能力逐步迁移到标准化插件 API，并完善插件包的安装、校验、卸载和目录分发流程。

## 更新内容

- 新增标准化插件清单、能力声明、权限模型、生命周期和宿主服务接口，为后续插件独立发布提供稳定契约。
- 新增安全插件包仓库，支持 `.lcp` 插件包的签名校验、安装、状态查询和完整卸载。
- 新增插件目录校验与安装来源约束，减少损坏、重复或来源不可信的插件进入运行环境。
- 完善游戏宿主服务和排行榜策略：默认多人对局超过一名玩家即可计榜，单机游戏可按游戏规则计榜，并允许插件自定义有效对局阈值。
- 拆分官方插件、视觉识别插件、插件 SDK 与插件目录仓库，主程序和插件可以独立迭代与发布。
- 官方插件仓库新增签名打包和持续集成校验，可生成供主程序安装的标准 `.lcp` 包。
- 延续大富翁 3D、聊天会话管理、频道临时系统通知及排行榜持久化等 0.7.2 功能优化。

## 更新要求

本版本为非强制的预览版更新。客户端检测到新版本后会提示更新，用户可以自行选择是否安装。
