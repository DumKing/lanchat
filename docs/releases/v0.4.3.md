# LanChat v0.4.3

本版本聚焦公告通知入口、WebView 内存治理和私聊通话稳定性。

## 本版重点

- 左侧底部新增公告铃铛入口；存在本机未处理公告或待确认通知时显示红点。
- 历史公告仅展示发给本机的通知，列表可点击查看详情；待确认通知支持从详情重新提交，普通公告可在详情中确认关闭。
- 超管通知审核继续仅展示本机下发的通知，避免接收通知与审核记录混在一起。
- 头像选择后自动压缩为 256 x 256 WebP，并使用受控 Blob URL 缓存，降低 Base64 重复解码的内存占用。
- 图片消息列表使用缩略图和懒加载；点击后才下载原图。图片本地缓存限制为 300MB，并按最近使用时间自动清理。
- 聊天记录改为 60 条视口渲染，向上按页加载；阅读历史时不会被新消息强制拉回底部。
- 设置新增内存诊断，可查看 JS 堆、图片缓存、消息缓存、占用较高的会话和头像。
- 修复语音通话无声：远端音频流独立挂载并主动恢复播放，收起通话面板或切换独立窗口也不会中断声音。
- 设置新增 GitHub API Token：可选配置 Fine-grained Token，保存至系统凭据库，用于避免 GitHub 匿名更新检查被限流；Token 不会同步到局域网设备。

## 下载与更新

- Windows 可下载安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- 绿色版解压后运行 `lanchat.exe`；系统缺少 WebView2 Runtime 时需先安装 Microsoft Edge WebView2 Runtime。
- macOS 可下载 DMG 安装包；未签名版本首次打开时可能需要在系统安全设置中确认。

## 更新策略

本 Release 为普通更新；客户端检测到新版本后会提示下载，也可以稍后安装。
