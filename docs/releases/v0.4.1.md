# LanChat v0.4.1

本版本聚焦私聊通话、桌宠快捷操作与频道成员体验的稳定性修复。

## 本版重点

- 语音和视频通话会主动申请麦克风与摄像头权限；拒绝、设备缺失或被占用时保留通话窗口并提供重新尝试。
- 修复接听通话后因短暂网络状态变化导致通话窗口消失的问题。
- 桌宠的接听与拒绝操作会自动打开主窗口并定位到对应私聊，同时写入通话系统通知。
- 设置新增通话权限入口，可手动重新授权麦克风或摄像头。
- 发送抖一抖成功后，发送方也会写入系统通知，明确送达结果。
- 私有频道支持普通成员主动退出；群主侧会同步更新成员列表并显示系统通知。
- 私聊会话标题、聊天标题和消息发送者优先展示当前昵称或备注。

## 下载与更新

- Windows 可下载安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- 绿色版解压后运行 `lanchat.exe`；系统缺少 WebView2 Runtime 时需先安装 Microsoft Edge WebView2 Runtime。
- macOS 可下载 DMG 安装包；未签名版本首次打开时可能需要在系统安全设置中确认。
