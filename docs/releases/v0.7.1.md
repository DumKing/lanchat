# LanChat v0.7.1

本版本继续完善局域网多人《大富翁》的完整对局体验、房间交互与桌宠稳定性。

## 更新内容

- 完善 40 格大富翁棋盘：地产、起点、机场、地价翻倍、监狱和随机事件均有独立视觉与完整规则说明。
- 地产支持小屋、洋房、地标三档随机建筑外观，按玩家颜色展示，并直接标注对应过路费与等级信号格。
- 新增停留卡；乌龟、停留、监狱和免罪卡的回合优先级与扣减逻辑已统一。
- 事件横幅改为常驻最近三条，按真实发生顺序展示；左上事件日志同步保留完整记录并自动滚动到最新消息。
- 玩家卡片显示骰序、准备状态、在线状态、地产数、背包数量及当前增益/减益；点击可定位棋盘上的对应玩家。
- 房间聊天与玩家卡片分区显示，输入框和发送按钮限制在右上聊天区域内，不再遮挡玩家操作。
- 对局中心、投骰动画、逐格移动、地块操作、结算与再来一局流程进一步优化。
- 修复桌宠在屏幕右下角反馈告警时可能跨屏移动并缩放异常的问题。

## 更新要求

本版本为强制更新。低于 `0.7.1` 的客户端在检测到该版本后需要完成更新，才能继续使用。
