# LanChat v0.5.0

本版本新增摄像头人脸识别告警能力，并将识别结果接入现有桌宠、局域网告警和外部推送体系。

## 本版重点

- 新增摄像头人脸识别监测，可维护本地已知人员资料和人脸特征。
- 支持 YuNet 人脸检测与 SFace 特征识别模型，模型随安装包内置。
- 只对识别命中的人员触发具名告警，匿名人脸不会产生告警记录。
- 人脸告警使用独立来源标识，可与普通“狼来了”告警区分统计。
- 人脸识别告警可触发桌宠、局域网广播和配置的企业微信/钉钉外部推送。
- 摄像头媒体流与通话媒体流统一协调，避免摄像头占用导致语音/视频通话异常。
- 摄像头识别告警自动弹窗增加设置开关，默认关闭，避免影响日常使用。
- 保留上一版本的消息实时刷新、聊天自动滚动和 GitHub 更新 Token 配置能力。

## 使用说明

- 首次启用摄像头监测时需要授予摄像头权限。
- 建议在光线稳定、正面角度下录入人员特征，并使用多个角度的样本提高识别稳定性。
- 人脸数据和识别结果保存在本机，不上传到 LanChat 服务端；局域网内仅广播告警事件。
- Windows 提供安装包和 `lanchat-windows-portable.zip` 绿色免安装版。
- macOS 提供 DMG 安装包。

## 更新策略

本 Release 为普通更新，检测到新版本后可选择稍后安装。
