# LanChat v0.3.3

LanChat v0.3.3 重点完善消息提醒体验，并修复中文输入法在频道聊天中被页面刷新打断的问题。

## 本版重点

- 托盘收到新消息后，在原位置以“正常图标 / 透明图标”交替闪烁，不再显示黑色占位框。
- 鼠标悬停托盘图标时显示各频道或联系人对应的未读消息数量。
- 频道消息支持识别 `@我` 和 `@所有人`，聊天列表显示提及提醒。
- 进入频道后提供提及消息快捷定位按钮，可直接滚动并高亮对应消息。
- 修复中文输入法尚未确认候选词时，拼音字母被页面定时刷新清除的问题。
- 输入法候选词确认期间按 Enter 不再误发送消息。
- GitHub Release 发布成功后可按仓库变量配置向企业微信群机器人发送 Markdown 通知。

## 下载建议

- Windows 用户可下载安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- 绿色版解压后直接运行 `lanchat.exe`；如果系统缺少 WebView2 Runtime，请先安装 Microsoft Edge WebView2 Runtime。
- macOS 用户可下载 DMG 安装包；未签名版本首次运行时可能需要在系统安全设置中确认打开。

## 更新提醒说明

本 Release 会附带 `lanchat-update.json`，更新策略为非强制更新：

```json
{
  "version": "0.3.3",
  "force": false,
  "min_supported_version": "0.0.0"
}
```

客户端检测到新版本后会显示更新弹窗和设置入口升级角标，用户可以关闭提醒后继续使用。
