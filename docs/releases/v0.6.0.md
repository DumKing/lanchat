# LanChat v0.6.0

本版本完成视觉识别运行时重构，发布可切换、可校验的本地视觉模型目录，并修复 Windows 发布包启动即退出的问题。

## 视觉识别

- 新增模型中心，可下载、安装和切换轻量巡检、均衡识别、灵敏巡检三种模型配置。
- 模型目录和模型包经过签名与完整性校验，客户端只接受受信任的发布内容。
- 激活模型配置时自动应用对应的推荐采样频率、识别阈值和连续命中参数。
- 摄像头策略区域统一管理识别开关与参数，移除重复入口。

## 稳定性

- 修复 Cargo 自动发现发布辅助工具后，Tauri 误将签名工具打包为 `lanchat.exe` 的问题。
- 主程序入口已固定为 `src/main.rs`，新增回归校验避免后续发布包启动即退出。
- 发布流水线补齐 Linux 签名工具依赖并修复模型包重复复制问题。

## 下载与更新

- Windows 提供安装包和绿色免安装包。
- macOS 提供 DMG 安装包。
- 本版本为正式更新，不强制安装；当前最低支持版本为 `0.5.1`。
