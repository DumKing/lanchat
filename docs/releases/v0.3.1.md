# LanChat v0.3.1

LanChat v0.3.1 是强制升级版本。旧版本检测到该版本后，会进入强制更新提示，必须下载安装新版本后才能继续使用。

## 本版重点

- 增加版本更新检查能力，支持启动后每日自动检查、设置页手动检查和强制更新锁定提示。
- 设置入口增加升级角标；普通更新会弹出显著提醒，强制更新会弹出不可关闭窗口。
- 修复局域网频道编辑公告、解散频道等操作异常时跳转错误页面的问题。
- 修复头像使用 base64 图片后仍显示字母头像的问题。
- 增加构建时间戳版本号，并在设备详情中展示对方软件版本和构建时间。
- 优化桌宠无告警状态下单击打开主窗口的行为。

## 下载建议

- Windows 用户可下载安装包，或下载 `lanchat-windows-portable.zip` 绿色免安装版。
- 绿色版解压后直接运行 `lanchat.exe`；如果系统缺少 WebView2 Runtime，请先安装 Microsoft Edge WebView2 Runtime。

## 强制更新说明

本 Release 会附带 `lanchat-update.json`：

```json
{
  "version": "0.3.1",
  "force": true,
  "min_supported_version": "0.3.1"
}
```

客户端检测到该配置后，如果本机版本低于 `0.3.1`，会要求安装新版本。
