# LanChat v0.6.0-1 预览版

这是视觉识别运行时重构的首个预览版本，面向愿意提前体验模型中心与可切换模型配置的用户。

## 视觉识别

- 模型中心去除重复的运行控制，统一由摄像头策略区域管理识别开关与参数。
- 内置轻量巡检、均衡识别、灵敏巡检三个可切换模型配置，针对普通办公笔记本提供不同的帧率和识别阈值建议。
- 模型配置支持下载、签名校验、安装与切换；激活时会应用该配置推荐的采样与识别参数。
- Release 同步发布经过签名验证的模型目录和模型压缩包，便于后续按需下载安装。

## 注意事项

- 此版本为预览版，不启用强制更新；建议先在测试设备上体验。
- 模型包需要网络下载，首次使用请保留足够的磁盘空间。
