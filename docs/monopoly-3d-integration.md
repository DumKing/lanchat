# 大富翁平面 / 3D 共用房间

现有游戏目录仍只有一个大富翁入口，房间类型继续使用 `monopoly`。进入房间后，在邀请、玩法规则和排行榜所在的顶部操作栏切换“平面 / 3D”。按钮仅修改本地展示状态，不发出房间动作，不重新创建游戏，不影响其他玩家选择的视图。默认使用 3D 视图，并可随时切回原平面视图。

`src/components/MonopolyBoard3D.vue` 是纯展示组件。父页面把真实地块、建筑外观、收费、神明／路障／查封／翻倍状态、目标合法性以及逐格动画位置转换成展示数据。组件点击返回地块索引，统一交给原来的 `handleMonopolyTileClick`，因此机场、道具等目标校验仍沿用原逻辑。

两种模式共用玩家、日志、聊天、骰子、道具、购买／放弃及结算的状态和交互。3D 上方为立体棋盘，底部左侧为两行玩家卡片、右侧为对局中心；加宽侧栏上方为事件日志、下方为聊天。底部两区等宽，高度以对局中心完整内容为准，不设置对局信息内部滚动。聊天已独立为 `MonopolyRoomChat.vue`，使用软件的 NInput/NButton，保留回车处理、发送和新消息滚动。切换使用 `v-show` 保留镜头缩放和平移，支持 60%～220% 缩放、拖动、复位和俯视／斜视。

3D 横幅通过插槽复用平面版横幅模板、人物／神明图标和事件颜色，只展示当前最新一条消息，锚定棋盘对角线交点并随镜头变换，不拦截鼠标。建筑、地标和空地贴图底座向地块前缘校准，城名放在底座铭牌。

日志沿用平面版 10px 字号及 20px 行高，单行省略、悬浮显示全文。玩家选择弹窗的颜色变量补充了实际色值，避免 Teleport 后无法继承棋盘容器颜色，悬浮和键盘聚焦均突出背景及边框。

透明资源 `public/games/monopoly/items/board-items.png` 包含路障、天使、恶魔、财神、穷鬼和翻倍金币；地块物品显示在建筑前方，神明附身后跟随玩家显示。沿用既有规则：神明拾取后附身 3 回合，路障拦停并消耗，不附身。

资源使用现有建筑、四角地标和摇奖机，人物使用根据原头像生成的 `public/games/monopoly/avatars/player-characters.png`。棋盘、公园和高亮跟随软件主题，玩家颜色按当前骰序匹配原头像。

## 验证

- `npx vue-tsc --noEmit`
- `npm run test:monopoly`
- `npm run test:monopoly-room`
- `npm run test:monopoly-ui`
- `npx vite build`
- 浏览器使用正式组件验收选点、移动及显示切换后的状态和缩放保留，入口 `previews/monopoly-component.html`（运行 `node previews/serve-component.mjs`）。该验收页不包含在软件入口中。

本次未执行两个原生客户端之间的局域网端到端对局；网络协议与规则引擎没有变更。
