# 桌宠图标与纯随机动作设计

## 目标

- 桌宠设置列表优先显示资源包根目录的 `icon.png`。
- 图标缺失或无法解码时，依次回退 `preview.png`、`Idle` 第一帧。
- 每个状态从对应目录的动作中等概率随机选择，不读取 `weight`。
- 动作选择、动作数量、停顿和持续时间由 `manifest.json` 的状态配置控制。

## 设计

资源扫描阶段按 `icon.png -> preview.png -> Idle 第一帧` 验证并提供图标。设置页资源列表可折叠，展开后以图标为主；右键资源可编辑动作节奏配置。

运行时按状态生成等概率动作组。`Idle / Alert / Move` 在配置的停留周期内播放动作组；`Interact` 只随机播放一个完整动作；`Life` 随机播放配置数量的动作，并在动作间按配置范围随机停顿。存在方向时优先过滤同方向动作；没有同方向动作时回退该状态全部动作，再回退 Idle。

拖动桌宠时立即进入 `Move`，按方向随机生成移动动作组并循环到拖动结束。蹦迪移动方式由本机设置选择：`linear` 连续线性移动，`jump` 使用蹲下、跃起、落地节奏分段移动。

`repeat`、`once` 都以完整帧序列作为一轮；`ping-pong` 以正向加反向作为一轮。状态变化、拖动方向变化或资源包变化时立即重建动作组。

## 验证

- Rust 单元测试覆盖图标优先级、损坏图标回退、候选方向过滤和动作周期。
- 静态 UI 测试确保设置页优先消费 `icon_path`。
- 运行 `cargo test`、`cargo check` 和 `npm run build`。
