# LanChat 摄像头人物识别增强设计

## 目标

在现有 YuNet + SFace 人脸识别链路上增加人体检测与 Person ReID，使远距离、侧身、背身等看不清正脸的场景仍可产生人物线索，同时严格区分识别可靠级别。

## 识别分级

- **确认识别**：当前画面的人脸特征达到策略阈值。可显示“检测到【人员】”。
- **疑似识别**：未达到人脸确认条件，但人体外观 ReID 达到疑似阈值。必须显示“疑似检测到【人员】”，不得伪装成确定结果。
- 人体外观会受衣着、遮挡、光照和摄像机角度影响，因此只作为疑似线索。

## 推理链路

1. 摄像头帧继续进入现有 YuNet + SFace 链路。
2. 同一帧运行 YOLOX 人体检测，提取完整人体区域。
3. 人体区域进入 YoutuReID，生成 768 维 L2 归一化特征。
4. 人脸与人体模板均对同一人员的多张参考图执行 Top-3 加权：`0.60 / 0.28 / 0.12`，不足三张时按实际权重归一化。
5. 人脸先判定；命中则输出确认。未确认的人再依据人体分数输出疑似。
6. 两种结果都沿用连续命中、冷却和反馈机制；命中级别写入告警记录并广播。

## 资源与兼容

- `manifest.json` 升级到 schema 3，新增可选 `personDetector`、`personRecognizer`。
- 模型缺失或加载失败时仅关闭人体增强，现有人脸识别继续工作。
- 旧的单图、单人脸特征自动迁移成样本记录。
- 局域网协议新字段均提供 serde 默认值，旧客户端仍能解码基础告警。

## 数据模型

`face_person_samples` 增加人体特征及模型版本；自动告警增加 `recognition_level`、`face_confidence`、`body_confidence`。照片只保存在目标设备本地，广播仍只发送告警结果。

## 性能边界

- 人体链路只使用 CPU ONNX，沿用现有单帧互斥，忙时丢帧而不排队。
- 最多处理一帧中置信度最高的 5 个人，最多保存每人 12 张参考图。
- 不保存摄像头画面；调试预览继续只使用短生命周期 Blob URL。
