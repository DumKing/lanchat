# 青蛙桌宠动作素材更新设计

## 目标

- 普通报警保留“惊讶 -> 生气 -> 告警”三帧，但“生气”必须是独立生成的新动作，不与告警图重复。
- 待机循环移除“开心、害羞、轻蹦迪”，替换为三帧同风格、低幅度、可连续播放的动作。
- 保持当前 4 x 4 主动作图集和既有动作索引结构，避免扩大 Rust 侧加载与绘制范围。

## 视觉方案

新待机三帧为：

1. 轻微抬头：身体保持正坐，头部与视线小幅向上。
2. 低头观察：身体保持正坐，头部与视线小幅向下。
3. 左右轻晃：身体只做轻微重心偏移，四肢位置稳定，可与待机帧自然衔接。

新“生气”帧要求：保持绿色本体，不做整只橙红染色；眉眼收紧、嘴角压低、前爪轻握，表达生气但不进入最终告警爆发状态。最终告警帧继续承担红橙色强化和高强度表情。

所有新图保持当前青蛙的圆润比例、3D 软质材质、正面机位、统一光照、透明背景、主体居中和完整边缘，不加入文字、图标、闪电、阴影底座或其他装饰。

## 动作节奏

- 待机以呼吸 A/B/C 为基础，每隔数秒插入一次轻微抬头、低头观察或左右轻晃，中间回到待机帧，避免连续大动作。
- 普通报警使用“惊讶 -> 生气 -> 告警”，每帧约 340 ms 循环。
- 蹦迪报警图集与侧身移动逻辑保持不变。

## 接入与验证

- 新素材先保存到 `public/pet-assets/preview-candidates/`，并更新 `frog-pet-motion-preview.html` 供逐帧预览。
- 确认后重新组装 `public/pet-assets/frog-3d-actions-alpha.png`，更新 `native_frog_pet.rs` 的动作常量和待机时间轴。
- 验证透明通道、主体覆盖范围、帧间尺寸一致性，以及普通报警三帧不是重复图。
- 运行桌宠脚本测试、`cargo check` 和前端构建。
