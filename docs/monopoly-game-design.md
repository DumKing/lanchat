# LanChat 局域网大富翁游戏设计

## 1. 目标与范围

在 LanChat 既有的局域网游戏房间框架内，提供一款 2 至 4 人、回合制、平面棋盘大富翁游戏。游戏强调地产连排、神明附身、道具干预与现金经营；全局游戏状态由房主裁决并同步给所有玩家。

第一版不包含匹配、机器人、观战结算奖励、付费数值、跨房间排行榜或断线托管之外的复杂服务端能力。

## 2. 创建房间与胜负

### 2.1 房间参数

房主创建房间时设置：

| 参数 | 范围 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 玩家数量 | 2 至 4 人 | 2 人 | 满足最少人数且所有人准备后开始 |
| 开局金币 | 5000 至 50000，步长 1000 | 5000 | 影响初始经营空间和神明现金基数 |
| 总完整回合数 | 5 至 50 | 20 | 所有未破产玩家各被安排一次行动，记为一个完整回合 |
| 单回合限时 | 固定 30 秒 | 30 秒 | 防止对局被单个玩家卡住 |

### 2.2 胜负与破产

- 达到设定的完整回合数后结算；如果只剩一名未破产玩家，则立即结束。
- 最终排名**只按当前金币**计算，地产、建筑、联排、道具和神明不折算资产，也不在结束时自动出售。
- 金币相同则并列。
- 玩家需要支付费用但现金不足时，可以先卖建筑、卖地产；仍无法支付则破产。
- 破产后：地产的建筑等级保留并转为银行暂持，道具、神明和异常状态清空，不能继续行动。

### 2.3 资产处置

| 操作 | 回收金额 | 结果 |
| --- | ---: | --- |
| 拆除建筑 | 对应建筑直接购买价的 50% | 三级降为二级，二级降为小屋 |
| 卖出地产 | 当前建筑等级直接购买价的 50% | 地块转为银行暂持，建筑等级保留 |

该处置仅用于补足本次应付款，不允许把地产当作结束前的任意套现工具，避免最后一回合出现无意义的集中抛售。

## 3. 棋盘

棋盘为顺时针平面环形，共 40 格：

- 四个角落：起点、飞机场、地价翻倍、监狱。
- 每条边有 9 个非角落格：前 4 个地产、中央 1 个随机事件、后 4 个地产。
- 因此一共 32 个地产、4 个随机事件和 4 个角落。

每四块连续地产是一个固定地产区。随机事件格和角落会天然切断地产连排；全盘最多出现 8 组四格连排。地产区只决定连排边界，不影响价格。

## 4. 地产状态、统一价格与联排

### 4.1 四种地产状态

地产只有以下四种状态，不存在“地基”状态：

| 状态 | 说明 |
| --- | --- |
| 空地 | 无归属；落到该格的玩家可购买或放弃 |
| 小屋 | 购买空地后立即成为小屋，可收取基础过路费；也可由银行暂持 |
| 二级建筑 | 小屋升级而来，过路费更高；也可由银行暂持 |
| 三级建筑 | 最高等级，过路费最高；也可由银行暂持 |

玩家再次落在自己的小屋或二级建筑时，系统自动免费将其升一级；三级建筑不可继续升级。

### 4.2 全图统一价格

所有 32 块地产使用完全相同的价格和收费规则，不再区分地产区价格档位。

| 地块状态 | 首次或直接购买价 | 升级方式 | 过路费 |
| --- | ---: | ---: | ---: |
| 空地 | 350 | - | - |
| 小屋 | 银行暂持时 500 | 空地购买后直接形成小屋 | 500 |
| 二级建筑 | 银行暂持时 1500 | 再次踩中自己的小屋时免费自动升级 | 1000 |
| 三级建筑 | 银行暂持时 3500 | 再次踩中自己的二级建筑时免费自动升级 | 2000 |

- 空地购买价 350，等于小屋直接购买价 500 的七折；购买完成后地块直接成为该玩家的小屋。
- 破产或出售后，地块由银行暂持，建筑等级不降级、不产生过路费。
- 其他玩家之后踩到银行暂持地块时，可以按该地块当前建筑等级的直接购买价买下：小屋 500、二级建筑 1500、三级建筑 3500；也可放弃。
- 银行暂持地块不属于任何玩家，不参与联排。原所有者的联排、查封、神明影响和地价翻倍标识均立即重算；地价翻倍标识不随银行暂持地产保留。

### 4.3 联排

- 同一玩家拥有同一地产区中相邻的 2 至 4 块、且这些地产均未被查封时，自动形成对应连续段的联排。
- 玩家踩到该联排中的任一格，需要支付这一连续段中**所有地块当前过路费之和**。
- 连排最多四格，不会跨越随机事件格或角落。
- 地价翻倍、建筑升降、抢占、出售、恶魔与查封都会立即重算联排。

示例：玩家拥有连续的 `1、2、3、4` 四块地产，查封第 `3` 块后，`1+2` 仍为两连排，第 `4` 块为独立地产；查封结束后自动恢复四连排。

## 5. 回合、移动与落点结算

### 5.1 正常回合

1. 房主确认当前玩家和 30 秒倒计时。
2. 处理本回合开始时的神明、乌龟、转向、监狱等状态。
3. 玩家可使用一张主动道具，或直接掷骰。
4. 投掷一枚 1 至 6 点骰子；指定卡可替代本次随机骰子。
5. 逐格移动。移动途中遇到路障，立即在路障格停止，不再前进。
6. 按“神明优先、落点后续结算”处理目标格。
7. 轮到下一位玩家。

超时后由房主自动投掷骰子；自动玩家不购地、不建设、不使用主动道具。

### 5.2 优先级

移动时，路障优先截停路径；抵达最终格后按以下顺序结算：

1. 已持有神明的落点效果。
2. 神明格的拾取（新神明从下一次自己的回合生效）。
3. 地产购买、建设或收费；或随机事件、角落效果。
4. 联排、查封、翻倍等以本次结算后的实时状态为准。

### 5.3 起点

- 经过或落到起点，获得 200 金币。
- 同时随机升级自己名下一座已有建筑：小屋升为二级，二级升为三级。
- 没有可升级建筑时，仅获得金币。

### 5.4 飞机场

- 落到飞机场，可选择传送到除当前格外的任意一格。
- 传送后完整结算目标格效果。
- 传送到起点可领取起点奖励；传送到监狱则直接入狱。
- 传送不会再次触发飞机场，避免循环传送。

### 5.5 地价翻倍

- 落到该角落后，从自己名下随机选择一块地产，使其过路费永久提高一个倍率层级：第一次为 `×2`、第二次为 `×3`，以此类推。
- 没有可选地产时无效果。
- 翻倍率会叠加，地块会明确展示当前的 `×N` 标识。

### 5.6 监狱

- 落到监狱、被陷害卡或随机事件送入监狱后，关押 3 个自己的回合。
- 入狱期间不能移动、买地、升级、使用主动道具、参与抢占，也不能收取任何过路费。
- 第三个被跳过的回合结束后自动出狱；下一次从监狱格按当前方向正常移动。
- 免罪卡被动触发后，立即回到起点并正常结算起点奖励。

## 6. 神明系统

### 6.1 刷新与持续

- 神明可刷新在 36 个非角落格上，包括地产与随机事件格。
- 每 3 个完整回合结束时，若未拾取神明少于 2 个，随机刷新 1 个神明。
- 未拾取神明存续 2 个完整回合后消失。
- 玩家踩到神明格时立即获得附身；效果从下一次自己的回合开始生效。
- 每人最多持有一个神明，新神明覆盖旧神明。
- 神明持续 3 个自己的回合；入狱时被跳过的回合也计入。

神明现金基数 = 开局金币的 20%，最低 100、最高 500，按 50 取整。

### 6.2 神明效果

| 神明 | 获得时 | 持续期间的落点效果 |
| --- | --- | --- |
| 财神 | 每位对手向持有者支付一份神明现金 | 踩到敌方地产时，免除全部过路费，包括联排费 |
| 穷鬼 | 持有者向每位对手赠送一份神明现金 | 踩到敌方地产时，过路费乘以 2，包括联排费 |
| 天使 | 无 | 踩到任意已有建筑地产时，建筑升一级；三级不再升级 |
| 恶魔 | 无 | 踩到任意已有建筑地产时，三级降二级、二级降小屋、小屋降为空地 |

财神和穷鬼的现金转移只使用当前可用金币，不会因此直接触发破产。恶魔将小屋变为空地后，当前玩家可立即按空地规则购买或放弃。

## 7. 随机事件

踩到任意随机事件格后，从下列事件中随机选择一项；没有有效目标的事件会重抽：

1. 拆迁令：随机一座小屋变为空地。
2. 楼市下调：随机一座二级或三级建筑下降一级。
3. 强制征收：随机将一名玩家的一块地产转移给另一名玩家。
4. 临时拘捕：随机一名未入狱玩家进入监狱。
5. 财政补贴：所有未破产玩家获得 100 金币。
6. 富者济贫：金币最多者向金币最少者支付 200 金币。
7. 城市改造：随机一座建筑免费升一级。
8. 维护支出：有建筑的玩家支付维护费，每座建筑 50，单次最多 250。
9. 产权纠纷：随机一块小屋变为空地。
10. 租金假日：随机一个地产区在下一个完整回合内免收过路费。

## 8. 道具系统

### 8.1 获取与限制

- 对局开始时，每位玩家默认获得 3 张道具卡；初始三张不重复，且最多包含 1 张强力卡。
- 每逢完整回合 3、6、9 等结束，所有未破产且背包未满的玩家各获得一张随机道具卡，入狱玩家也可获得。
- 背包最多持有 3 张道具卡。
- 发卡时背包已满 3 张，则该玩家本轮不发卡，不触发补抽或自动替换。
- 玩家可在自己的回合内主动弃置任意一张道具卡；弃置不占用本回合的主动道具使用次数。
- 每个自己的回合可以多次使用主动道具，为了游戏公平性考虑，初始回合默认只能使用一次主动道具。
- 入狱期间不能使用主动道具。

强力卡为抢占卡、陷害卡、掠夺卡和查封卡；任意时刻每位玩家背包中最多持有 1 张强力卡。抽卡命中已不允许持有的卡时，在剩余合法卡池中重新抽取。

### 8.2 抽卡概率与动态平衡

所有抽卡由房主使用同一个随机源完成，并将抽卡结果与计算依据写入房间日志。默认基础概率如下：

| 卡牌 | 基础概率 | 定位 |
| --- | ---: | --- |
| 免罪卡 | 10% | 防守 |
| 抢占卡 | 3% | 强力翻盘 |
| 陷害卡 | 8% | 强力干扰 |
| 翻倍卡 | 9% | 经营增强 |
| 指定卡 | 14% | 移动控制 |
| 路障卡 | 17% | 路线干扰 |
| 乌龟卡 | 13% | 节奏压制 |
| 转向卡 | 10% | 路线重置 |
| 掠夺卡 | 6% | 强力资源干扰 |
| 查封卡 | 10% | 经营压制 |

为避免领先者持续滚雪球，抽卡时计算“落后补偿等级”：

- 金币不高于全体未破产玩家金币中位数的 40%，获得 2 点补偿；不高于 70%，获得 1 点补偿。
- 已拥有建筑数量不高于中位数的 50%，获得 2 点补偿；低于中位数，获得 1 点补偿。
- 补偿点数达到 3 点时，启用落后卡池；1 至 2 点时，在基础概率和落后卡池概率之间线性插值；0 点时使用基础概率。

落后卡池概率如下，既提高翻盘机会，也避免把抢占卡变成高频卡：

| 卡牌 | 落后卡池概率 |
| --- | ---: |
| 免罪卡 | 12% |
| 抢占卡 | 8% |
| 陷害卡 | 8% |
| 翻倍卡 | 14% |
| 指定卡 | 12% |
| 路障卡 | 13% |
| 乌龟卡 | 10% |
| 转向卡 | 8% |
| 掠夺卡 | 10% |
| 查封卡 | 5% |

抢占卡基础概率始终只有 3%；即使玩家同时处于低金币和低建筑状态，最高也只提升到 8%，并且仍受“背包最多一张强力卡”限制。

### 8.3 卡牌清单

| 卡牌 | 使用方式与效果 |
| --- | --- |
| 免罪卡 | 被动；进入监狱时自动触发，回到起点并结算起点奖励 |
| 抢占卡 | 选择其他玩家的一块地产，连同建筑与翻倍标识转移给自己 |
| 陷害卡 | 指定一名未入狱玩家，使其进入监狱 3 个自己的回合 |
| 翻倍卡 | 指定任意已购地产，使过路费永久提高一个倍率层级；可重复叠加并显示当前 `×N` |
| 指定卡 | 指定下一次骰子点数为 1 至 6 |
| 路障卡 | 放置于任意 40 格；任何玩家经过或落到该格都会被截停、结算该格，随后路障消失 |
| 乌龟卡 | 指定一名玩家，使其接下来 3 个自己的回合每回合只能前进 1 格 |
| 转向卡 | 指定一名玩家，立即永久反转其移动方向；直到再次被转向卡改变 |
| 掠夺卡 | 指定一名其他玩家，随机掠夺其背包中一张道具；目标无道具时使用失败 |
| 查封卡 | 查封任意小屋、二级或三级建筑，持续其所有者接下来 3 个自己的回合 |

路障对包括布置者在内的所有玩家生效；它没有自然到期时间，直到第一次触发才消失。

### 8.4 查封

- 被查封地产不能收取过路费。
- 被查封地产不参与联排计算，并会切断连续联排。
- 查封期间地产仍归原所有者，建筑等级和翻倍标识不丢失。
- 查封到期后自动恢复收费与联排资格。

## 9. 状态冲突示例

- 玩家携带恶魔，移动途中先被路障拦到敌方小屋：先被路障截停，再由恶魔将小屋降为空地，随后当前玩家可购买该空地。
- 玩家携带财神踩到敌方四连排：直接免除四块地产合计的全部费用。
- 玩家踩到被查封的联排成员：该成员不收费，也不加入联排总费用；仅计算同一所有者连续且未查封的其他地产段。如果刚好踩到连排的查封地块，则不收费
- 玩家被转向后使用指定卡：指定的是点数，方向仍沿当前反向状态执行。
- 乌龟与转向同时存在：玩家按反向方向前进 1 格。

## 10. 局域网同步与断线恢复

### 10.1 权威模型

- 房主为唯一权威：生成骰子、随机事件、神明、卡牌和超时操作结果。
- 客户端只提交意图，例如投骰、买地、选传送目标、使用道具；自有地产升级由房主在落地结算时自动完成。
- 房主验证意图合法后更新状态，并广播状态增量。
- 每个动作拥有唯一 `action_id`，每个状态拥有递增 `revision`，用于去重与乱序恢复。

### 10.2 断线与重连

- 断线玩家保留房间席位，直到房主结束房间或该玩家破产。
- 当前玩家断线或超时，按自动操作规则继续，避免整局阻塞。
- 重连客户端请求房主完整快照，再应用后续增量。
- 所有关键事件写入房间日志：骰子、交易、收费、神明、道具、入狱、查封、随机事件与破产。

## 11. 界面与交互

- 中央使用平面环形棋盘，显示地产归属颜色、建筑等级、过路费、翻倍、查封、路障和神明。
- 建筑采用等距 3D 图集：小屋、洋房、地标各有多种款式；首次购买和每次升级由房主随机选定一种并随房间状态同步。玩家归属分别显示四种玩家颜色，银行暂持或无人持有的建筑统一显示灰色，破产后建筑款式保留。
- 随机事件格显示摇奖机图标，并在事件结算时通过棋盘横幅播报结果。
- 左右两侧显示玩家头像、金币、持有神明、道具数量、移动方向、监狱状态和 30 秒倒计时。
- 当前玩家、骰子、系统事件和结算提示置于棋盘中心。
- 房间聊天放在右上角的半透明区域，不遮挡棋盘。
- 联排收费、神明附身、查封、抢占、入狱与破产使用短动画和系统播报强化反馈。

## 12. 验收标准

1. 40 格棋盘结构恒定，32 地产、4 事件、4 角落数量正确。
2. 空地购买后直接成为小屋，且只存在空地、小屋、二级、三级四种状态。
3. 2 至 4 格连续同属且未查封地产能正确计算联排总过路费。
4. 查封可准确切断联排，持续三个所属玩家回合后自动恢复。
