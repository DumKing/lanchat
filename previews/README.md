# 大富翁 3D 交互预览

在仓库根目录运行 `node previews/serve-monopoly-3d.mjs`，然后访问：

http://127.0.0.1:1426/previews/monopoly-3d.html

这是独立设计原型，未注册到正式游戏目录，也没有接入多人联机、经济结算或道具执行。骰子仅演示玩家逐格移动；玩家资产、建筑等级和归属均为视觉示例。

棋盘左上角提供缩小、放大和复位按钮，缩放范围为 60%～220%。鼠标滚轮以指针位置为中心缩放，按住拖动可平移棋盘；复位恢复 100% 和默认位置。页面的 Ctrl／Command 滚轮缩放快捷键保持原行为。

界面按 LanChat 默认窗口 1180×760、最小窗口 960×640 做紧凑布局适配，棋盘随可用高度伸缩，底部操作栏固定在可见区域，右侧详情独立滚动。主题变量直接取自 `src/styles/global.css`，右上角可预览四种软件配色。当前仍是独立预览页面，尚未嵌入正式游戏房间。

## 复用内容

- 从 `src/games/monopoly.ts` 直接读取 40 格棋盘、城市名称和地产价格常量。
- 复用 `public/games/monopoly/buildings/style-{1,2,3}.png` 三套建筑与 `avatars/player-portraits.png` 玩家头像。
- 起点、机场、地价翻倍、监狱复用 `corners/corner-landmarks.png`，事件格复用 `events/slot-machine.png`。
- 空地沿用原版地台的绘制思路，用 SVG 表现地砖和小灌木，颜色跟随软件主题；原版没有独立空地图片。
- 四个全身人物使用 `avatars/player-characters.png`，与四个玩家头像按相同 2×2 顺序对应，走格时随棋子移动。
- 树木、公园、水池和棋盘厚度由 SVG 绘制。

## 视觉路线

1. **当前推荐：等距投影 + 直立贴图。** 可直接复用建筑资源，开销低；视角变化有限，建筑不会随镜头旋转展示背面。
2. CSS 透视棋盘：实现轻便，但倾斜后文字和房屋容易扁平，点击和层级需要额外处理。
3. WebGL 场景：支持自由旋转、光照和镜头动画，但需要新增渲染依赖与模型资源，不适合此次先看伪 3D 预览的范围。

正式软件已按最终确认方案使用同一大富翁入口、同一房间，在界面切换平面 / 3D。原型仍独立保留；正式接入说明见 `docs/monopoly-3d-integration.md`。目标选择由原规则校验器决定，坐标仅决定显示和命中位置。

- JavaScript 语法检查通过。

服务使用临时目录缓存，避免影响主应用已有 Vite 缓存；仅监听本机 `127.0.0.1:1426`。

## 人物素材生成记录

使用内置 ImageGen，以原版 `player-portraits.png` 为参考生成透明背景的 2×2 全身人物图集。提示要求：保持原头像的脸部、服饰和 3D 卡通材质；左上红色礼帽绅士，右上蓝色飞行员，左下绿色探险犬，右下紫色魔女；完整双脚、等距视角、相同高度、无圆形头像边框、无文字、透明背景。图片保存为 `public/games/monopoly/avatars/player-characters.png`。
